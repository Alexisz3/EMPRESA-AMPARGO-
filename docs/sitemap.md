# Planned Sitemap

This is the initial information architecture. Route names and localized slugs should be confirmed when content is approved.

| Page | English route | Spanish route | Primary purpose |
| --- | --- | --- | --- |
| Home | `/en` | `/es` | Establish value, trust, and a clear path to request a quote. |
| Services | `/en/services` | `/es/services` | Explain the approved service offering. |
| Projects | `/en/projects` | `/es/projects` | Show real completed work and work in progress. |
| About | `/en/about` | `/es/about` | Introduce the company using verified information. |
| Contact | `/en/contact` | `/es/contact` | Show approved contact details and location. |
| Request an Estimate | `/en/quote` | `/es/quote` | Validate and collect project information for later delivery integration. |
| Privacy Policy | `/en/privacy` | `/es/privacy` | Explain how information submitted through the site is handled. |

## Proposed project categories

- Bathrooms
- Outdoor / patio construction
- Kitchens / countertops
- Work in progress

Category names are working labels based on the available project context and must be verified against the final photo library.

## Navigation principles

- Keep the primary navigation concise and consistent in both languages.
- Keep a quote-request action visible on key pages without overwhelming the content.
- Preserve the equivalent page when a visitor changes language.
- Include a useful localized 404 page and footer navigation before launch.
